## Como usar (custo zero até casar)

Estas skills **não** carregam por padrão. O protocolo de entrada
(`nucleo/01-protocolo-entrada.md`) identifica o domínio da tarefa; se casar
com uma categoria abaixo, abra **só** a `SKILL.md` da skill correspondente:

```
biblioteca/<categoria>/<skill>/SKILL.md
```

Nenhuma tarefa casa? Segue só com o núcleo — ele já cobre o padrão.
Nunca invente conteúdo de skill: leia o arquivo real antes de aplicar.
