# Instagram Ads Direct Response Marketing Skill

Gera copy de alto-impacto para Instagram Feed e Stories usando técnicas comprovadas de direct response marketing 2026 + temperamentos humanos para maximizar conversão.

## Como Usar

Forneça um **BRIEFING ESTRUTURADO** com:

```
BRIEFING:
Persona: [descrição do prospect ideal — idade, profissão, contexto]
Problema: [dor específica que o prospect sente]
Solução: [como seu produto/serviço resolve]
Números: [estatísticas, provas sociais, resultados mensuráveis]
Tom: [humorous / contrarian / data-driven]
```

Exemplo:
```
BRIEFING:
Persona: Empreendedor digital B2B, 28-42 anos, dono de agência, frustrado com falta de garantias
Problema: Agências de SEO prometem mas não entregam. Risco total do cliente.
Solução: Artemis SEO — único sistema que assume o risco contratualmente
Números: 1.7M impressões orgânicas em 30 dias. +2866% vs anterior.
Tom: contrarian, hu humor irreverente
```

## O que a Skill Entrega

**4 variações de copy** — uma para cada temperamento humano:

### **Colérico** (ação, competição, domínio)
- Hook de urgência + confronto
- Linguagem direta, imperativa
- CTA agressivo, "ganhe", "domine", "não perca"
- Proof: números que mostram liderança

### **Melancólico** (excelência, garantia, detalhe)
- Hook de confiabilidade + análise
- Linguagem precisa, específica, com substância
- CTA: "conheça o sistema", "veja os resultados"
- Proof: dados detalhados, garantia contratual

### **Sanguíneo** (otimismo, comunidade, movimento)
- Hook de transformação + possibilidade
- Linguagem esperançosa, leve, relacional
- CTA: "comece hoje", "se junte", "descubra"
- Proof: histórias de sucesso, transformação

### **Fleumático** (estabilidade, praticidade, eficiência)
- Hook de simplicidade + resultado garantido
- Linguagem descomplicada, pragmática
- CTA: "toque para saber como", "é simples"
- Proof: processos, sistemas, garantia de tranquilidade

## Técnicas de Direct Response 2026 Implementadas

### **Hook (0-3 segundos)**
Vai direto ao ponto. Problema-agitação-curiosidade. Sem introdução.

**Tipos de hooks testados:**
- **Contrarian**: "Tudo que você sabe sobre X está errado..."
- **Problem-Agitation**: "Se você ainda está pagando tráfego pago..."
- **Curiosity Gap**: "Ninguém fala sobre X, mas..."
- **Bold Claim**: "A maioria das ferramentas é só sabor SEO..."
- **Pattern Interrupt**: "Vou ser direto: agências de SEO não garantem."

### **Problem-Agitation-Solution (PAS)**
1. Identifica o problema específico
2. Agita a emoção (medo, frustração, perda)
3. Apresenta a solução (Artemis)

### **WIIFM (What's In It For Me)**
Foco no que o prospect GANHA, não no que você faz. "Você cuida do negócio, nosso sistema atrai pessoas do Google."

### **Social Proof + Números**
Estatísticas reais, resultados mensuráveis, garantias. 1.7M impressões. +2866% vs anterior.

### **Urgência & Scarcity**
- "em 30 dias"
- "(e com garantia contratual)"
- "é aquilo que não podemos dizer aqui"
- Deadline implícito: exclusividade, especialidade

### **CTA Direto**
Ação clara. Verbo imperativo. Sem confusão. "Toque no botão", "Conheça a solução", "Veja como funciona."

## Princípios Fundamentais

**1. Copy Pura**
Sem "Headline", "CTA", "Copy". Apenas o que entra no Meta Ads Manager. Máximo impacto.

**2. Sem Fluff**
Cada palavra trabalha. Sem adjetivos vazios. Linguagem específica, crível.

**3. Temperamento > Tom Único**
Não vale uma copy genérica para todos. Coléricos compram por conquista. Melancólicos por segurança. Sanguíneos por esperança. Fleumáticos por praticidade.

**4. Números Reais**
Social proof é o diferencial. Use estatísticas, porcentagens, garantias mensuráveis.

**5. Tensão + Resolução**
Hook cria tensão. Copy agita. CTA resolve. Fluxo hipnótico.

## Referência: Os 4 Temperamentos (Marsili)

Baseado na tradição aristotélico-tomista estudada por Italo Marsili:

- **Colérico**: Bilioso, ativo, orientado para ação. Quer dominar, conquistar, liderar.
- **Melancólico**: Contemplativo, profundo, busca excelência. Quer segurança, análise, perfeição.
- **Sanguíneo**: Otimista, relacional, movimento. Quer comunidade, transformação, esperança.
- **Fleumático**: Equilibrado, prático, busca estabilidade. Quer simplicidade, eficiência, tranquilidade.

## Checklist de Qualidade

- [ ] Hook interrompe o scroll (primeiras 2-3 palavras são irrecusáveis)
- [ ] Problema é específico (não genérico)
- [ ] Solução é diferenciador claro
- [ ] Números/provas são reais e contextualizados
- [ ] WIIFM — o que o prospect ganha está evidente
- [ ] Urgência está subtil mas presente
- [ ] CTA é ação clara (não vaga)
- [ ] Temperamento é consistente em toda a copy
- [ ] Sem clichês de copywriting (não é "você merece", "é simples", "revoluções")
- [ ] Soa humano, crível, específico

## Notas de Implementação

- Cada copy é **independente** — pode rodar em paralelo em diferentes públicos
- Temperamentos diferentes convertem públicos diferentes — teste qual traz o melhor ROI
- Rotação criativa: troque a copy **toda semana** para evitar ad fatigue
- Números devem ser reais e auditáveis — social proof é sua arma
- CTA deve levar a **landing page otimizada** (não só página genérica)
